# 워치 동기화 광고 게이트 테스트 가이드

## 목적

경기 시작 푸시, 라이브 상세 화면 ON 토글, 워치 앱 수락 응답에서 같은 워치 동기화 광고 게이트가 적용되는지 확인한다. 홈 LIVE 경기 카드 탭은 광고 게이트 없이 LiveGame으로 이동해야 한다.

## 사전 조건

- 모바일 앱과 워치 앱이 모두 설치되어 있어야 한다.
- 모바일 설정 화면의 워치 상태 카드가 `워치 앱 설치됨`으로 표시되어야 한다.
- AdMob DEBUG 빌드에서는 Google 테스트 광고가 표시되어야 한다.
- 같은 경기 광고 재시청 생략을 테스트하려면 테스트 전 모바일 앱의 광고 시청 기록을 초기화한다.
  - iOS: 앱 삭제 후 재설치 또는 `watchSyncAdViewed.<gameId>` UserDefaults 삭제
  - Android: 앱 데이터 삭제 또는 `watch_sync_ad_ledger` SharedPreferences 삭제

## 공통 기대 UX

1. 사용자가 워치 관람을 시작하는 진입점을 누른다.
2. 모바일에 `워치로 보시겠습니까?` 팝업이 표시된다.
3. 팝업 본문에 `광고 관람 후 동기화됩니다.`가 표시된다.
4. [취소]를 누르면 워치 동기화가 시작되지 않고 현재 위치에 머문다.
5. [확인]을 누르면 보상형 전면 광고가 표시된다.
6. 광고를 끝까지 보면 해당 경기가 워치에 동기화된다.
7. 같은 경기에서 다시 동기화할 때는 광고 없이 즉시 동기화된다.

## 모바일 진입점 테스트

### 1. 홈 LIVE 카드 탭

- GIVEN 홈 화면에 미동기화 LIVE 경기 카드가 보인다
- WHEN 사용자가 LIVE 경기 카드를 탭한다
- THEN `워치로 보시겠습니까?` 팝업이 뜨지 않는다
- AND LiveGame으로 바로 이동한다
- AND 워치 동기화는 자동으로 시작되지 않는다

### 2. 경기 시작 푸시 탭

- GIVEN 워치 앱이 설치된 상태에서 경기 시작 푸시를 받았다
- WHEN 사용자가 푸시를 탭한다
- THEN 모바일 앱은 홈 화면으로 착지한다
- AND 홈 위에 `워치로 보시겠습니까?` 팝업이 뜬다
- WHEN [취소]를 누른다
- THEN 홈 화면에 그대로 남는다
- WHEN [확인] 후 광고를 완료한다
- THEN LiveGame으로 이동하고 워치에 경기 진행 상황이 표시된다

### 3. 라이브 상세 화면 ON 토글

- GIVEN 사용자가 LIVE 경기 상세 화면에 있고 워치 동기화 토글이 OFF다
- WHEN 사용자가 토글을 ON으로 바꾼다
- THEN `워치로 보시겠습니까?` 팝업과 `광고 관람 후 동기화됩니다.` 문구가 표시된다
- WHEN [확인] 후 광고를 완료한다
- THEN 토글이 ON 상태가 되고 워치에 경기 진행 상황이 표시된다
- WHEN 토글을 OFF로 바꾼다
- THEN `워치 동기화를 끄시겠습니까?` 확인만 표시되고 광고는 표시되지 않는다

## 워치 앱 비활성 상태 테스트

### watchOS

- GIVEN Apple Watch에서 야구봄 Watch 앱이 꺼져 있거나 백그라운드 상태다
- WHEN iPhone에서 워치 동기화 프롬프트를 전송한다
- THEN 즉시 팝업 표시가 보장되지 않을 수 있다
- WHEN 사용자가 Watch 앱을 직접 열거나 워치가 WatchConnectivity 백그라운드 전달을 처리한다
- THEN 대기 중인 프롬프트가 있으면 `경기를 관람하겠습니까?` 팝업이 표시되어야 한다
- WHEN 워치 팝업에서 [확인]을 누른다
- THEN iPhone 앱이 실행 중이면 보상형 광고가 표시되고, 광고 완료 후 워치에 경기 진행 상황이 표시된다

주의: watchOS는 iPhone 앱이 Apple Watch 앱을 강제로 전면 실행해 팝업을 띄우는 흐름을 안정적으로 보장하지 않는다. 실사용 UX는 워치 알림 탭 또는 사용자의 Watch 앱 실행을 폴백으로 검증한다.

### Wear OS

- GIVEN Wear OS 워치에서 야구봄 Watch 앱이 꺼져 있거나 백그라운드 상태다
- WHEN Android 모바일에서 워치 동기화 프롬프트를 전송한다
- THEN 워치 화면이 켜지고 `경기를 관람하겠습니까?` 팝업이 표시되어야 한다
- WHEN [확인]을 누른다
- THEN 워치 응답이 모바일로 전달되고 모바일 광고 게이트가 진행되어야 한다
- AND 모바일 앱이 백그라운드/종료 상태라면 `워치 관람 광고 확인` 알림이 표시되어야 한다
- WHEN 사용자가 알림을 탭한다
- THEN 모바일 앱이 열리고 보상형 광고가 표시된 뒤 워치에 경기 진행 상황이 표시된다

## 업데이트 안내 테스트

- GIVEN 앱 버전이 릴리즈 노트 버전과 일치하고 사용자가 해당 버전 안내를 아직 보지 않았다
- WHEN 앱을 실행한다
- THEN What's New 팝업에 `워치 관람 시작 방식 변경` 문구가 표시된다
- WHEN 사용자가 확인한다
- THEN 같은 버전에서 다시 자동 표시되지 않는다
- WHEN 설정 화면에서 업데이트 안내를 직접 연다
- THEN 같은 문구를 다시 확인할 수 있다

## 회귀 체크

- 워치 앱 미설치 상태에서 푸시를 탭하면 팝업 없이 홈에 머물러야 한다.
- 워치 앱 설치 상태 카드가 `워치 앱 설치됨`이면 워치 테스트 진입점이 표시되어야 한다.
- 광고 로드 실패 또는 표시 실패 시에도 동기화는 허용되어야 한다.
- 광고를 끝까지 보지 않고 닫으면 광고 시청 기록은 저장되지 않아야 한다.
- 같은 경기 광고 시청 기록이 저장된 뒤에는 푸시 탭, 상세 토글, 워치 수락 응답에서 광고를 생략해야 한다.
