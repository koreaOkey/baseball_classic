## ADDED Requirements

### Requirement: Android 시스템 바 다크 마감
Android 모바일 앱은 시스템 상태바와 내비게이션바가 앱의 다크 배경과 시각적으로 이어지도록 표시해야 한다(MUST).

#### Scenario: 홈 화면 시스템 바 표시
- **GIVEN** 사용자가 Android 모바일 앱 홈 화면을 열었을 때
- **WHEN** 화면이 렌더링되면
- **THEN** 상태바와 내비게이션바는 앱 다크 배경과 어긋나는 밝은 영역 없이 표시된다

#### Scenario: 하단 내비게이션과 시스템 내비게이션 연결
- **GIVEN** 하단 탭이 표시되는 Android 모바일 화면일 때
- **WHEN** 사용자가 화면 하단을 볼 때
- **THEN** 앱 하단 내비게이션과 시스템 내비게이션 영역은 같은 다크 톤으로 자연스럽게 이어진다

### Requirement: Android 하단 내비게이션 시각 밀도
Android 모바일 앱의 하단 내비게이션은 탭 기능을 유지하면서 앱의 다크 스포츠 톤에 맞는 낮은 시각 밀도로 표시해야 한다(MUST).

#### Scenario: 탭 선택 상태 표시
- **GIVEN** 사용자가 Android 모바일 앱의 하단 탭 화면에 있을 때
- **WHEN** 특정 탭이 선택되어 있으면
- **THEN** 선택된 탭은 응원팀 색으로 명확히 구분되되, 큰 배경 강조가 콘텐츠보다 더 눈에 띄지 않는다

#### Scenario: 탭 라벨 표시
- **GIVEN** 하단 탭 라벨이 표시될 때
- **WHEN** 앱의 디자인 토큰이 적용되면
- **THEN** 라벨은 Android 화면에서 과하게 크거나 넓게 보이지 않는 크기와 자간으로 표시된다

### Requirement: Android 홈 경기 카드 정돈
Android 모바일 홈 화면의 경기 카드는 경기 상태, 팀, 점수, 보조 액션이 한눈에 구분되도록 정돈된 계층으로 표시해야 한다(MUST).

#### Scenario: 라이브 경기 카드 표시
- **GIVEN** 홈 화면에 진행 중인 경기가 있을 때
- **WHEN** 경기 카드가 렌더링되면
- **THEN** LIVE 상태, 이닝, 팀명, 점수는 카드 내부에서 겹치지 않고 충분한 여백을 가진다

#### Scenario: 응원팀 카드 강조
- **GIVEN** 홈 화면에 응원팀 경기가 있을 때
- **WHEN** 응원팀 카드가 렌더링되면
- **THEN** 응원팀 강조는 카드 내용을 압도하지 않는 테두리와 배지로 표시된다

#### Scenario: 카드 보조 액션 표시
- **GIVEN** 홈 경기 카드에 잠금화면 또는 Watch 액션이 표시될 때
- **WHEN** 사용자가 카드를 볼 때
- **THEN** 보조 액션은 점수 정보보다 낮은 계층으로 표시되고 탭 가능한 상태는 유지된다

### Requirement: Android 라이브 상세 점수판 균형
Android 모바일 라이브 상세 화면의 점수판은 팀명, 점수, 현재 주자·카운트 상태를 좁은 화면에서도 균형 있게 표시해야 한다(MUST).

#### Scenario: 점수판 중앙 상태 영역
- **GIVEN** 사용자가 Android 모바일 라이브 상세 화면에 진입했을 때
- **WHEN** 점수판이 렌더링되면
- **THEN** 중앙 상태 영역은 양 팀 점수 영역을 밀어내지 않고 한 화면 폭 안에서 균형 있게 표시된다

#### Scenario: 선수 이름 보조 텍스트
- **GIVEN** 점수판에 투수와 타자 이름이 표시될 때
- **WHEN** 이름이 길거나 화면 폭이 좁으면
- **THEN** 보조 텍스트는 점수판의 주요 점수와 팀명 영역을 침범하지 않는다

### Requirement: Android 스토어 스크린샷 홈 화면
Android Play Store용 홈 화면 스크린샷은 Android 앱의 실제 시각 개선 방향을 반영해야 한다(MUST).

#### Scenario: Android 홈 스크린샷 렌더
- **GIVEN** Android 홈 스크린샷을 생성할 때
- **WHEN** 렌더러가 화면을 출력하면
- **THEN** 홈 화면의 카드 밀도, 팀명 표기, 상단 여백, 하단 여백은 Android 모바일 앱의 개선된 디자인 방향과 일관된다

#### Scenario: iOS 스크린샷과 구분
- **GIVEN** Android와 iOS 스토어 스크린샷을 비교할 때
- **WHEN** 두 플랫폼의 홈 화면을 나란히 보면
- **THEN** Android 스크린샷은 iOS 렌더러의 단순 축소판이 아니라 Android용 화면 비율과 밀도를 반영한다
