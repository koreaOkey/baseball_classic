# venting-mode — 사용자 노출 명칭 "빠따존" 델타

## ADDED Requirements

### Requirement: 사용자 노출 명칭
분풀이 모드의 사용자 노출 명칭은 "빠따존"을 MUST 사용한다. "빠따존"은 장소·모드
명칭으로만 쓰고, 행위 표현("분풀이 완료!", "직접 지목한 분풀이 대상")은 "분풀이"를
유지한다. 내부 코드명(venting — 클래스·패키지·API 경로·DB 테이블·푸시 kind·딥링크)은
변경하지 않는다.

#### Scenario: 단독 명칭 노출
- GIVEN 빠따존이 제목·배지로 단독 등장하는 화면일 때(룸 배지, 대상선택 화면 제목,
  워치 선택 페이지, What's New 제목)
- WHEN 해당 텍스트를 렌더하면
- THEN "💢 빠따존" 형식으로 이모지를 앞에 붙여 표시한다

#### Scenario: 문장·버튼·아이콘 동반 노출
- GIVEN 빠따존이 문장 성분이거나 버튼 레이블이거나, 리딩 아이콘·이모지가 이미 있는
  UI(설정 행, 홈카드 헤더, 패배 팝업, 테스트 버튼)일 때
- WHEN 해당 텍스트를 렌더하면
- THEN 이모지 없이 "빠따존" 텍스트만 사용한다

#### Scenario: 행위 표현 유지
- GIVEN 완파 화면과 커스텀 대상 표시명일 때
- WHEN 해당 텍스트를 렌더하면
- THEN "분풀이 완료!"·"직접 지목한 분풀이 대상"을 그대로 표시한다

#### Scenario: 패배 유도 푸시 카피
- GIVEN 경기 종료 시 패배팀 팬에게 발송하는 유도 푸시일 때
- WHEN 푸시를 구성하면
- THEN 제목 "오늘은 아쉽게 졌어요 💢", 본문 "{팀} 팬, 빠따존에서 오늘 스트레스 풀고
  가세요."를 사용하고 kind=venting_loss 등 페이로드 식별자는 유지한다
