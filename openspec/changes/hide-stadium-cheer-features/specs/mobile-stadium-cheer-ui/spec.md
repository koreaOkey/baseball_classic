## MODIFIED Requirements

### Requirement: 현장 응원 사용자 노출 표면 제어

운영 준비 전까지 모바일 앱은 현장 응원 테마와 설정 토글을 사용자에게 노출하지 않아야 한다(SHALL). 단, `내 팀` 탭 진입점은 별도 활성화 플래그에 따라 노출될 수 있어야 한다(SHALL).

#### Scenario: 현장 응원 테마 숨김
- **GIVEN** 현장 응원 테마 노출 플래그가 꺼져 있다
- **WHEN** 사용자가 워치 테마 화면을 연다
- **THEN** 베이직 테마만 표시되어야 한다
- **AND** 현장 응원 섹션 토글과 목업 안내 문구는 표시되지 않아야 한다

#### Scenario: 경기장 응원 설정 토글 숨김
- **GIVEN** 경기장 응원 설정 노출 플래그가 꺼져 있다
- **WHEN** 사용자가 설정 화면을 연다
- **THEN** 경기장 응원 토글은 표시되지 않아야 한다
- **AND** 저장된 경기장 응원 설정 값과 백엔드 게이트 로직은 삭제되지 않아야 한다

#### Scenario: 내 팀 탭은 별도 플래그로 노출
- **GIVEN** 내 팀 탭 활성화 플래그가 켜져 있다
- **WHEN** 사용자가 앱 하단 탭을 확인한다
- **THEN** 현장 응원 테마와 설정 토글이 숨겨져 있어도 내 팀 탭은 표시되어야 한다
