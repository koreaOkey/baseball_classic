## ADDED Requirements

### Requirement: 라이브 중 앰비언트 허용
Wear OS 앱은 라이브 경기 중 화면을 무기한 인터랙티브 밝기로 유지하지 않아야 한다(SHALL NOT). 손목을 내리면 앰비언트 모드로 전환하되 라이브 스코어 표시는 유지한다.

#### Scenario: 손목 내림 시 앰비언트 전환
- **GIVEN** 라이브 경기를 워치 앱에서 보는 중일 때
- **WHEN** 사용자가 손목을 내려 시스템이 앰비언트 전환을 요청하면
- **THEN** 워치는 앰비언트 화면으로 전환해 스코어를 저전력으로 계속 표시한다
- **AND** 진동·데이터 수신은 중단 없이 유지된다

#### Scenario: 손목 올림 시 즉시 복귀
- **GIVEN** 앰비언트 상태로 라이브 경기가 표시 중일 때
- **WHEN** 사용자가 손목을 올리면
- **THEN** 워치는 최신 경기 상태의 인터랙티브 화면으로 즉시 복귀한다

#### Scenario: 데이터 두절 시 화면 상시 켜짐 해제
- **GIVEN** 라이브 판정이 남아 있으나 마지막 경기 데이터 수신 후 기준 시간이 경과했을 때
- **WHEN** 앱 화면이 표시되면
- **THEN** 워치는 화면 상시 켜짐 정책을 적용하지 않는다
