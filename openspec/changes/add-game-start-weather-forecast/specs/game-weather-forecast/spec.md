## ADDED Requirements

### Requirement: 경기 시작 예보 요약
시스템은 예정 경기의 경기 시작 시점 날씨 예보 요약을 제공해야 한다(MUST).

#### Scenario: 예정 경기 예보 요약 제공
- **GIVEN** 예정 경기의 구장과 시작 시간이 확인되었을 때
- **WHEN** 클라이언트가 경기 목록을 조회하면
- **THEN** 경기 시작 시점과 가장 가까운 예보 시간의 날씨 요약을 함께 받을 수 있다

#### Scenario: 경기 시작 시점 명시
- **GIVEN** 예정 경기 예보 요약이 제공될 때
- **WHEN** 클라이언트가 요약 문구를 구성하면
- **THEN** “경기 시작 예보”와 “N시 기준”을 표시할 수 있는 정보가 포함된다

#### Scenario: 돔구장 예보 처리
- **GIVEN** 경기가 돔구장에서 열릴 때
- **WHEN** 클라이언트가 경기 목록을 조회하면
- **THEN** 외부 날씨 대신 날씨 영향이 적다는 요약을 받을 수 있다

#### Scenario: 예보 미제공 폴백
- **GIVEN** 날씨 예보를 조회할 수 없거나 예보 범위 밖 경기일 때
- **WHEN** 클라이언트가 경기 목록을 조회하면
- **THEN** 경기 목록은 정상 제공되고 해당 경기의 날씨 요약은 제공되지 않는다

### Requirement: 당일 시간별 구장 예보
시스템은 오늘 경기의 구장별 시간별 날씨 예보를 제공해야 한다(MUST).

#### Scenario: 시간별 예보 조회
- **GIVEN** 오늘 예정 경기의 날씨 요약이 표시되어 있을 때
- **WHEN** 사용자가 상세 날씨를 요청하면
- **THEN** 해당 구장의 오늘 시간별 날씨 예보 목록을 시간순으로 받을 수 있다

#### Scenario: 경기 시작 시간대 강조 정보
- **GIVEN** 오늘 시간별 예보 목록이 제공될 때
- **WHEN** 경기 시작 시점과 가장 가까운 예보가 존재하면
- **THEN** 클라이언트가 해당 시간대를 강조할 수 있는 정보가 포함된다

#### Scenario: 시간별 예보 실패
- **GIVEN** 시간별 예보를 조회할 수 없을 때
- **WHEN** 사용자가 상세 날씨를 요청하면
- **THEN** 클라이언트는 재시도 가능한 실패 상태를 표시할 수 있다
