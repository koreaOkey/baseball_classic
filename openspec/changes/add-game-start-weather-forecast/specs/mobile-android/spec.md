## MODIFIED Requirements

### Requirement: 당일 경기 목록
앱은 오늘의 경기 목록을 표시해야 한다(MUST).

#### Scenario: 경기 목록 로드
- GIVEN 사용자가 앱을 실행했을 때
- WHEN 홈 화면이 표시되면
- THEN 당일 KBO 경기 목록을 백엔드에서 조회하여 카드 형태로 표시한다

#### Scenario: 예정 및 진행 중 경기의 경기 시작 예보 표시
- **GIVEN** 오늘의 경기 목록에 예정 또는 진행 중 경기와 경기 시작 예보가 있을 때
- **WHEN** 홈 경기 카드가 표시되면
- **THEN** 팀 정보 아래에 “경기 시작 예보 · 구장 · N시 기준 · 날씨 · 기온 · 강수확률” 형식의 날씨 정보를 표시한다

#### Scenario: 종료 경기 예보 미표시
- **GIVEN** 오늘의 경기 목록에 종료된 경기가 있을 때
- **WHEN** 홈 경기 카드가 표시되면
- **THEN** 경기 시작 예보 정보는 표시하지 않는다

#### Scenario: 홈팀 표기
- **GIVEN** 오늘의 경기 카드에 홈팀과 원정팀이 표시될 때
- **WHEN** 팀명이 렌더링되면
- **THEN** 홈팀명 옆에 “(홈)” 텍스트를 표시한다

#### Scenario: 오늘 시간별 예보 바텀시트
- **GIVEN** 오늘의 예정 또는 진행 중 경기 카드에 경기 시작 예보가 표시되어 있을 때
- **WHEN** 사용자가 날씨 정보를 탭하면
- **THEN** 해당 구장의 오늘 시간별 날씨 예보를 바텀시트로 표시한다

### Requirement: 다가오는 경기 목록
앱은 응원팀의 다가오는 경기를 홈 화면에 표시해야 한다(MUST).

#### Scenario: 다가오는 경기 예보 표시
- **GIVEN** 응원팀의 다가오는 예정 경기와 경기 시작 예보가 있을 때
- **WHEN** 다가오는 경기 카드가 표시되면
- **THEN** 세로 구분선 없이 경기 시작 예보 정보를 표시한다

#### Scenario: 다가오는 경기 홈팀 표기
- **GIVEN** 다가오는 경기 카드에 홈팀과 원정팀이 표시될 때
- **WHEN** 팀명이 렌더링되면
- **THEN** 홈팀명 옆에 “(홈)” 텍스트를 표시한다
