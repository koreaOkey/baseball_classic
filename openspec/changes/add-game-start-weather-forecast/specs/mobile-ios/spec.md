## MODIFIED Requirements

### Requirement: 당일 경기 목록
앱은 오늘의 경기 목록을 표시해야 한다(MUST).

#### Scenario: 예정 경기의 시작 시간대 날씨 표시
- **GIVEN** 오늘의 경기 목록에 예정 경기와 시작 시간대 날씨가 있을 때
- **WHEN** 홈 경기 카드가 표시되면
- **THEN** 경기 시작 시간 아래에 “구장 · N시 날씨 · 상태 · 기온 · 강수확률” 형식의 날씨 정보를 표시한다

#### Scenario: 진행 중 경기 예보 미표시
- **GIVEN** 오늘의 경기 목록에 진행 중인 경기가 있을 때
- **WHEN** 홈 경기 카드가 표시되면
- **THEN** 시작 시간대 날씨 정보는 표시하지 않는다

#### Scenario: 홈팀 표기
- **GIVEN** 오늘의 경기 카드에 홈팀과 원정팀이 표시될 때
- **WHEN** 팀명이 렌더링되면
- **THEN** 홈팀명 옆에 “(홈)” 텍스트를 표시한다

#### Scenario: 오늘 시간별 예보 시트
- **GIVEN** 오늘의 예정 경기 카드에 시작 시간대 날씨가 표시되어 있을 때
- **WHEN** 사용자가 날씨 정보를 탭하면
- **THEN** 해당 구장의 오늘 시간별 날씨 예보를 시트로 표시한다

#### Scenario: 지난 시간대 예보 미표시
- **GIVEN** 오늘 시간별 예보 목록에 현재 시간보다 이전 시간대가 포함되어 있을 때
- **WHEN** 사용자가 날씨 정보를 탭하면
- **THEN** 지난 시간대 예보는 시트에 표시하지 않는다

#### Scenario: 날씨 상태 아이콘 표시
- **GIVEN** 시작 시간대 날씨 또는 시간별 예보에 날씨 상태가 있을 때
- **WHEN** 홈 경기 카드 또는 날씨 시트가 표시되면
- **THEN** 맑음, 구름많음, 흐림, 비, 눈, 천둥 계열을 구분할 수 있는 날씨 아이콘을 표시한다

### Requirement: 다가오는 경기 목록
앱은 응원팀의 다가오는 경기를 홈 화면에 표시해야 한다(MUST).

#### Scenario: 다가오는 경기 예보 표시
- **GIVEN** 응원팀의 다가오는 예정 경기와 시작 시간대 날씨가 있을 때
- **WHEN** 다가오는 경기 카드가 표시되면
- **THEN** 날짜와 시작 시간 아래에 세로 구분선 없이 시작 시간대 날씨 정보를 표시한다

#### Scenario: 다가오는 경기 홈팀 표기
- **GIVEN** 다가오는 경기 카드에 홈팀과 원정팀이 표시될 때
- **WHEN** 팀명이 렌더링되면
- **THEN** 홈팀명 옆에 “(홈)” 텍스트를 표시한다
