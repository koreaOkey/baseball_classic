## Why

경기 관람 전 사용자는 우산, 외투, 이동 여부를 빠르게 판단해야 하지만 홈 경기 카드에는 경기 시작 시점의 현장 날씨 정보가 없다. 오늘 경기와 다가오는 경기 카드에 경기 시작 예보를 제공하면 경기 전 의사결정을 앱 안에서 끝낼 수 있다.

## What Changes

- 백엔드는 KBO 경기장의 경기 시작 시점 날씨 요약과 오늘 시간별 예보를 제공한다.
- Android 홈의 오늘 경기 카드에는 예정 경기만 팀 정보 아래에 `경기 시작 예보 · 잠실 · 18시 기준 · 흐림 23° · 강수 30%` 형식의 날씨 컴포넌트를 표시한다.
- Android 홈의 다가오는 경기 카드에는 세로 구분선 없이 같은 의미의 경기 시작 예보를 정보 행으로 표시한다.
- Android 홈 경기 카드의 홈팀명 옆에는 `(홈)` 텍스트를 표시한다.
- 오늘 경기 카드의 날씨 컴포넌트를 탭하면 해당 구장의 오늘 시간별 예보를 바텀시트로 표시한다.
- LIVE/진행 중 경기와 종료된 경기에는 경기 시작 예보 컴포넌트를 표시하지 않는다.

## Capabilities

### New Capabilities
- `game-weather-forecast`: 경기 시작 시점 날씨 요약과 당일 시간별 예보 제공

### Modified Capabilities
- `mobile-android`: 홈 경기 카드와 다가오는 경기 카드의 날씨 및 홈팀 표기 요구사항 추가
- `infra`: 날씨 API 연동을 위한 백엔드 환경 변수 요구사항 추가

## Impact

- Backend API: `/games` 응답 확장, 경기별 시간별 날씨 조회 API 추가
- Backend config/services: 공공데이터포털 기상청 단기예보 API 키, 구장별 예보 좌표, 캐싱/폴백 처리
- Android app: `Game` 모델 파싱, 홈 경기 카드 UI, 날씨 상세 바텀시트
- External dependency: 공공데이터포털 기상청 단기예보 조회서비스
