# live-game-detail — 박스스코어 팀 토글 기본 선택·라벨 델타

## ADDED Requirements

### Requirement: 박스스코어 응원팀 기본 노출
경기 상세 박스스코어 탭의 팀 토글은 수동 선택 전에는 응원팀 기록을 기본으로 MUST
노출한다. 응원팀이 설정되지 않았거나 이 경기에 출전하지 않으면 선공인 어웨이 팀이
기본이다. 세그먼트 버튼 배치는 라인스코어 표기 순서(어웨이 왼쪽·홈 오른쪽)를 유지하고,
사용자의 수동 토글 선택은 기본값보다 우선한다.

#### Scenario: 응원팀이 홈일 때 기본 선택
- GIVEN 응원팀이 이 경기의 홈 팀일 때
- WHEN 박스스코어 탭에 처음 진입하면
- THEN 홈 팀 기록이 기본으로 표시된다

#### Scenario: 응원팀 미설정·미출전 시 기본 선택
- GIVEN 응원팀이 없거나 이 경기 양 팀 어디에도 해당하지 않을 때
- WHEN 박스스코어 탭에 처음 진입하면
- THEN 선공인 어웨이 팀 기록이 기본으로 표시된다

#### Scenario: 수동 토글 우선
- GIVEN 사용자가 토글로 다른 팀을 선택했을 때
- WHEN 같은 경기 상세 화면 안에서 박스스코어를 다시 보면
- THEN 수동 선택한 팀이 유지된다

### Requirement: 박스스코어 토글 라벨 "OO팀 기록"
팀 토글 라벨은 "OO팀 기록" 형식으로 MUST 표기한다(타자·투수 기록이 모두 노출되므로
"OO팀 타자" 금지). 타자 표에는 "타자 기록", 투수 표에는 "투수 기록" 제목을 각각 표시한다.

#### Scenario: 토글·표 제목 표기
- GIVEN 박스스코어 데이터가 로드됐을 때
- WHEN 박스스코어 탭을 렌더하면
- THEN 토글은 "OO팀 기록"(팀명 표시 스타일 설정 반영), 표 제목은 "타자 기록"·"투수 기록"으로 표시된다
