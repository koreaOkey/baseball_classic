# add-season-calendar-schedule

## Summary

홈의 응원팀 일정 팝업을 리스트가 아닌 달력 UI로 바꾸고, 백엔드가 시즌 미래 일정을 선적재/갱신하여 Android/iOS 앱이 9월까지의 일정을 안정적으로 조회할 수 있게 한다.

## Motivation

현재 홈 일정 팝업은 단순 리스트 형태이고, 앱은 날짜별 경기 조회를 반복해 향후 일정을 구성한다. 사용자는 응원팀의 남은 시즌 일정을 달력으로 훑어보고 날짜별 경기를 바로 선택하길 원한다.

또한 KBO 일정은 시즌 중 일부 구간까지만 먼저 공개되고, 8월 중순 이후 9월 말 일정이 추가 공개될 수 있다. 따라서 앱이 직접 크롤링하거나 단기 조회에 의존하기보다 백엔드가 공개된 미래 일정을 미리 수집하고 이후 공개 구간을 반복 갱신해야 한다.

## Scope

- 크롤러/디스패처가 오늘부터 지정 종료일까지 KBO 스케줄을 일괄 수집할 수 있게 한다.
- 8월 중순 이후 9월 말까지의 스케줄 갱신 정책을 설정 가능한 옵션으로 제공한다.
- 백엔드 경기 목록 API가 날짜 범위 조회를 지원하게 한다.
- Android/iOS 홈 일정 팝업을 달력 기반 UI로 변경한다.
- Android/iOS 앱은 범위 조회 결과를 로컬 캐시에 저장하고 달력 UI에 사용한다.

## Non-Goals

- 앱에서 네이버 스포츠 API를 직접 호출하거나 크롤링하지 않는다.
- 경기 상세 실시간 수집 방식은 변경하지 않는다.
- DB 스키마 변경은 필요하지 않은 방향을 우선한다.
- 워치 UI에 달력 화면을 추가하지 않는다.

## Risks

- 장기 범위 import는 네이버 API 호출 수가 늘어나므로 timeout, retry, empty day 처리를 보수적으로 해야 한다.
- 미래 일정은 변경될 수 있으므로 SCHEDULED/POSTPONED/CANCELED 상태만 안전하게 갱신하고 LIVE/FINISHED 회귀 방지는 유지해야 한다.
- 모바일 달력 UI는 화면 밀도가 높아 날짜 칸, 상태 badge, 하단 경기 목록이 작은 화면에서도 겹치지 않도록 해야 한다.
