# Game State Delta

## ADDED Requirements

### Requirement: 경기 목록 날짜 범위 조회
시스템은 클라이언트가 경기 목록을 날짜 범위로 조회할 수 있어야 한다(MUST).

#### Scenario: 날짜 범위 경기 조회
- GIVEN 지정한 날짜 범위 안에 저장된 경기가 있을 때
- WHEN 클라이언트가 시작일과 종료일로 경기 목록을 요청하면
- THEN 해당 범위의 경기 목록을 반환한다
- AND 결과는 경기 날짜, 시작 시간, 경기 식별자 순으로 정렬된다

#### Scenario: 단일 날짜 조회 호환
- GIVEN 기존 클라이언트가 단일 날짜로 경기 목록을 요청할 때
- WHEN 기존 날짜 파라미터가 전달되면
- THEN 기존과 동일하게 해당 날짜 경기만 반환한다

#### Scenario: 잘못된 날짜 범위
- GIVEN 종료일이 시작일보다 빠를 때
- WHEN 클라이언트가 경기 목록을 요청하면
- THEN 잘못된 요청으로 응답한다
