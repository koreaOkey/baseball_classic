## ADDED Requirements

### Requirement: 팀 표시 방식 선택
사용자는 응원팀을 팀명 또는 마스코트명 중 원하는 방식으로 표시하도록 선택할 수 있어야 한다(MUST).

#### Scenario: 신규 사용자 기본 선택
- **GIVEN** 사용자가 온보딩에서 응원팀을 선택했을 때
- **WHEN** 표시 방식 선택 팝업이 표시되면
- **THEN** 팀명 선택지가 기본 선택 상태로 표시된다

#### Scenario: 선택지 구성
- **GIVEN** 사용자가 두산을 응원팀으로 선택했을 때
- **WHEN** 표시 방식 선택 팝업이 표시되면
- **THEN** 시스템은 팀 로고와 함께 "두산" 팀명 선택지와 "베어스" 마스코트명 선택지를 표시한다

#### Scenario: 선택값 저장
- **GIVEN** 사용자가 표시 방식을 선택했을 때
- **WHEN** 적용을 완료하면
- **THEN** 시스템은 선택한 표시 방식을 영구 저장한다

#### Scenario: 팀 식별값 유지
- **GIVEN** 사용자가 표시 방식을 마스코트명 또는 팀명으로 바꾸었을 때
- **WHEN** 앱이 응원팀 식별, 경기 매칭, 테마 동기화, 구독 등록을 수행하면
- **THEN** 시스템은 기존 응원팀 코드를 그대로 사용한다

### Requirement: 기존 사용자 1회 선택
이미 응원팀을 선택한 사용자는 다음 앱 실행 시 표시 방식 선택 팝업을 1회 확인해야 한다(MUST).

#### Scenario: 기존 사용자 팝업 노출
- **GIVEN** 사용자가 이미 응원팀을 선택했고 표시 방식 선택을 확인한 적이 없을 때
- **WHEN** 앱 홈 화면에 진입하면
- **THEN** 시스템은 표시 방식 선택 팝업을 표시한다

#### Scenario: 기존 사용자 팝업 재노출 방지
- **GIVEN** 사용자가 표시 방식 선택 팝업에서 적용하거나 나중에 변경을 선택했을 때
- **WHEN** 앱을 다시 실행하면
- **THEN** 시스템은 같은 팝업을 자동으로 다시 표시하지 않는다

### Requirement: 표시 방식 변경
사용자는 설정에서 표시 방식을 다시 변경할 수 있어야 한다(MUST).

#### Scenario: 설정에서 변경
- **GIVEN** 사용자가 설정 화면에 진입했을 때
- **WHEN** 팀 설정 영역을 확인하면
- **THEN** 시스템은 현재 표시 방식과 변경 진입점을 제공한다

#### Scenario: 변경 즉시 반영
- **GIVEN** 사용자가 설정에서 표시 방식을 변경했을 때
- **WHEN** 앱 화면, 워치, 푸시 구독 동기화가 갱신되면
- **THEN** 시스템은 변경된 표시 방식을 이후 표시와 알림에 반영한다
