## ADDED Requirements

### Requirement: iOS 팀 표시 방식 온보딩
iOS 모바일 앱은 온보딩 중 응원팀 선택 후 팀 표시 방식 선택 팝업을 표시해야 한다(MUST).

#### Scenario: 온보딩 표시 방식 팝업
- **GIVEN** 사용자가 온보딩에서 응원팀을 선택했을 때
- **WHEN** 계속하기를 선택하면
- **THEN** 앱은 다음 단계로 이동하기 전에 팀명과 마스코트명 선택 팝업을 표시한다

#### Scenario: 팝업 선택지 로고 표시
- **GIVEN** 표시 방식 선택 팝업이 표시되었을 때
- **WHEN** 사용자가 선택지를 확인하면
- **THEN** 각 선택지 옆에 선택한 응원팀 로고를 표시한다

### Requirement: iOS 팀 표시 방식 적용
iOS 모바일 앱은 저장된 표시 방식에 따라 사용자-facing 팀 라벨을 표시해야 한다(MUST).

#### Scenario: 팀명 표시
- **GIVEN** 사용자의 표시 방식이 팀명일 때
- **WHEN** 홈, 경기 상세, 설정 화면이 팀 라벨을 표시하면
- **THEN** 앱은 "두산" 같은 팀명을 표시한다

#### Scenario: 마스코트명 표시
- **GIVEN** 사용자의 표시 방식이 마스코트명일 때
- **WHEN** 홈, 경기 상세, 설정 화면이 팀 라벨을 표시하면
- **THEN** 앱은 "베어스" 같은 마스코트명을 표시한다
