## ADDED Requirements

### Requirement: 응원팀 일정 팝업
앱은 홈 화면에서 사용자가 응원팀의 향후 경기 일정을 팝업으로 확인할 수 있어야 한다(MUST).

#### Scenario: 홈 달력 진입
- **GIVEN** 사용자가 응원팀을 선택한 상태로 홈 화면을 보고 있을 때
- **WHEN** 홈의 달력 영역을 탭하면
- **THEN** 응원팀 경기 일정 팝업이 표시된다

#### Scenario: 응원팀 미선택
- **GIVEN** 사용자가 응원팀을 선택하지 않은 상태일 때
- **WHEN** 홈의 달력 영역을 탭하면
- **THEN** 일정 조회를 시작하지 않고 응원팀 선택이 필요하다는 상태를 표시한다

#### Scenario: 일정 항목 표시
- **GIVEN** 응원팀의 향후 경기가 존재할 때
- **WHEN** 일정 팝업이 렌더링되면
- **THEN** 각 경기의 날짜, 시작 시간, 상대팀, 홈/원정 여부, 경기 상태를 표시한다

#### Scenario: 일정 없음
- **GIVEN** 조회 기간 안에 응원팀 경기가 없을 때
- **WHEN** 일정 팝업이 렌더링되면
- **THEN** 일정이 없다는 빈 상태를 표시한다

#### Scenario: 일정 조회 실패
- **GIVEN** 일정 조회 중 네트워크 또는 응답 오류가 발생했을 때
- **WHEN** 일정 팝업이 렌더링되면
- **THEN** 오류 상태와 다시 시도 동작을 표시한다

#### Scenario: 경기 상세 진입
- **GIVEN** 일정 팝업에 경기 항목이 표시되어 있을 때
- **WHEN** 사용자가 경기 항목을 탭하면
- **THEN** 앱은 해당 경기의 기존 상세 진입 흐름을 실행한다

### Requirement: 일정 조회 범위
앱은 모바일 네트워크 비용을 제한하기 위해 일정 팝업의 기본 조회 범위를 제한해야 한다(MUST).

#### Scenario: 기본 조회 범위
- **GIVEN** 사용자가 응원팀 일정 팝업을 열었을 때
- **WHEN** 앱이 일정을 조회하면
- **THEN** 오늘을 포함한 향후 30일 범위의 응원팀 경기를 조회한다

#### Scenario: 조회 결과 정렬
- **GIVEN** 여러 날짜의 응원팀 경기가 조회되었을 때
- **WHEN** 일정 팝업이 목록을 구성하면
- **THEN** 날짜와 시작 시간이 빠른 경기부터 표시한다
