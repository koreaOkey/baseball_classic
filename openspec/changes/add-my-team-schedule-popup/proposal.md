## Why

홈 화면은 오늘 경기와 일부 다가오는 경기만 보여주기 때문에 사용자가 응원팀의 전체 일정을 확인하려면 앱 밖의 일정표를 다시 찾아야 한다. 홈의 달력 영역을 일정 진입점으로 확장하면 응원팀 중심 사용 흐름을 유지하면서 경기 전후 탐색성을 높일 수 있다.

## What Changes

- 홈 화면의 날짜/달력 영역을 탭 가능한 일정 진입점으로 변경한다.
- 응원팀이 선택된 경우 응원팀의 향후 경기 일정을 팝업 형태로 표시한다.
- 일정 팝업은 날짜, 상대팀, 홈/원정, 시작 시간, 경기 상태를 구분해 보여준다.
- 팝업 내 경기 항목을 탭하면 기존 경기 상세 진입 흐름을 재사용한다.
- 응원팀 미선택, 로딩, 오류, 일정 없음 상태를 별도로 표시한다.
- 이번 변경은 MVP로 Android 모바일에 우선 적용하고, iOS 모바일은 동일 UX 요구사항을 명세에 반영한다.

## Capabilities

### New Capabilities
- `my-team-schedule-popup`: 홈에서 응원팀 경기 일정을 팝업으로 탐색하는 사용자 기능

### Modified Capabilities
- `mobile-android`: Android 홈 화면에 응원팀 일정 팝업 진입점과 표시 요구사항을 추가
- `mobile-ios`: iOS 홈 화면에도 동일한 응원팀 일정 팝업 요구사항을 추가

## Impact

- Android 모바일 홈 화면: 달력 영역 탭 처리, ModalBottomSheet, 일정 리스트 UI
- Android 모바일 데이터 계층: 기존 날짜별 경기 조회를 재사용한 응원팀 일정 조회 확장
- Backend API: 이번 MVP에서는 기존 `GET /games?date=YYYY-MM-DD`를 재사용하며 신규 API와 DB 마이그레이션은 필요하지 않음
- Watch Android/iOS: 홈 모바일 UX 변경만 해당하므로 워치 동작 영향 없음
