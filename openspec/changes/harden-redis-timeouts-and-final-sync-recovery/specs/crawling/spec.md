# crawling (delta)

## ADDED Requirements

### Requirement: 경기 종료 상태 동기화 재시도
디스패처는 크롤러 종료 시점 또는 중계 종료 판정 시점의 최종 상태 동기화가 실패하면 백오프로
재시도해야 한다(SHALL). 재시도 상한에 도달하면 포기하고 오류 로그를 남긴다.

#### Scenario: 백엔드 일시 장애 후 회수
- **Given** 경기가 종료됐고 크롤러가 정상 종료했다
- **And** 백엔드가 응답하지 않아 최종 상태 동기화가 실패했다
- **When** 백엔드가 복구된다
- **Then** 디스패처는 30초부터 시작해 최대 300초 간격으로 재시도해 종료 상태와 최종 점수를 백엔드에 반영한다
- **And** 회수 시 시도 횟수를 로그로 남긴다

#### Scenario: 재시도 상한
- **Given** 최종 상태 동기화 재시도가 30회 실패했다
- **Then** 재시도를 중단하고 오류 로그를 남긴다

### Requirement: 자정 스케줄 수집의 전날 회수
일일 스케줄 수집은 기본적으로 전날부터 시작해 백엔드 상태와 다른 종료 경기를 회수해야 한다(SHALL).
백엔드 상태와 같은 경기는 전송하지 않는다.

#### Scenario: 전날 고착 경기 회수
- **Given** 전날 경기가 백엔드에 진행 중으로 남아 있고 소스는 종료로 표시한다
- **When** 자정 일일 수집이 실행된다
- **Then** 전날 날짜가 수집 범위에 포함되어 해당 경기의 종료 상태·점수가 백엔드에 반영된다

#### Scenario: 변경 없는 경기 무전송
- **Given** 전날 경기가 백엔드에 이미 종료·동일 점수로 있다
- **When** 자정 일일 수집이 실행된다
- **Then** 해당 경기는 변경 없음으로 건너뛴다

### Requirement: 취소·연기 표기 경기의 크롤링 종료
크롤러는 상태 코드뿐 아니라 상태 텍스트(취소·우천취소·노게임·연기)로도 경기 종료를 판정해 폴링을
멈춰야 한다(SHALL). 중계 텍스트가 없는 경기 전 상태가 장시간 이어지면 정상 종료해 디스패처의
재판정에 맡긴다.

#### Scenario: 상태 코드가 갱신되지 않은 취소 경기
- **Given** 상태 코드는 경기 전이지만 상태 텍스트가 "경기취소"다
- **When** 크롤러가 스냅샷을 수집한다
- **Then** 이를 종료로 판정해 마지막 스냅샷 전송 후 폴링을 멈춘다

#### Scenario: 우천 중단은 종료가 아니다
- **Given** 상태 텍스트가 "우천 중단"이다
- **Then** 크롤러는 종료로 판정하지 않고 폴링을 계속한다

#### Scenario: 장시간 경기 전 상태
- **Given** 중계 텍스트 없이 경기 전 상태가 6시간 이상 이어진다
- **Then** 크롤러는 정상 종료하고 디스패처가 소스 상태를 다시 확인해 재시작 여부를 정한다
