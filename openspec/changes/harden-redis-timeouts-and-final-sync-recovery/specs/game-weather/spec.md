# game-weather (delta)

## ADDED Requirements

### Requirement: 기상 예보 상류 지연 격리
백엔드는 기상 예보 상류 API 가 느리거나 실패해도 다른 API 응답과 앱의 날씨 요청 시간 한도를
지켜야 한다(SHALL). 앱 요청 경로는 짧은 상한 시간으로 실패를 확정하고, 백그라운드 프리워밍은
긴 상한 시간으로 캐시를 채운다.

#### Scenario: 상류 지연 중 앱 요청
- **Given** 기상 예보 상류가 10초 이상 응답하지 않는다
- **When** 앱이 경기 시간대 날씨를 요청한다
- **Then** 백엔드는 5초 안에 응답을 돌려준다
- **And** 같은 격자·발표시각의 조회가 이미 진행 중이면 기다리지 않고 즉시 응답한다

#### Scenario: 마지막 성공 예보로 대체
- **Given** 이전 발표시각의 예보 조회가 성공한 적 있다(6시간 이내)
- **When** 새 발표시각 조회가 실패하거나 진행 중이다
- **Then** 마지막 성공 예보로 응답해 날씨가 비지 않는다

#### Scenario: 다른 요청 무영향
- **Given** 날씨 조회 여러 건이 상류 지연으로 대기 중이다
- **When** 경기 목록·상태 요청이 들어온다
- **Then** 날씨 조회와 별도 실행 자원을 쓰므로 지연 없이 응답한다
