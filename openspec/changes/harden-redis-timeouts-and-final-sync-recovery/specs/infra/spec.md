# infra (delta)

## ADDED Requirements

### Requirement: 캐시 계층 장애 격리
백엔드는 캐시 저장소에 대한 연결·명령·캐시 작업에 짧은 상한 시간을 두고, 상한 초과나 연결 실패를
캐시 미스로 취급해 원본 데이터 조회로 계속 진행해야 한다(SHALL). 캐시 저장소가 교체·재시작되더라도
API 응답이 중단되어서는 안 된다.

#### Scenario: 캐시 저장소 재배포 중 API 응답 유지
- **Given** 캐시 저장소 컨테이너가 교체되어 기존 주소로의 연결이 응답하지 않는다
- **When** 클라이언트가 경기 목록을 요청한다
- **Then** 백엔드는 수 초 안에 캐시를 포기하고 DB 에서 조회해 정상 응답한다
- **And** 캐시 실패 횟수를 카운터로 집계하고 경고 로그를 스로틀해 남긴다

#### Scenario: 이벤트 구독 연결 복구
- **Given** 이벤트 구독 연결이 서버 측에서 끊겼다
- **When** 재연결이 계속 실패한다
- **Then** 재시도 간격을 지수적으로 늘리되 10초 이내로 유지하며 계속 재시도한다
- **And** 재구독에 성공하면 간격을 초기값으로 되돌린다

#### Scenario: 응답 없이 사라진 캐시 피어 감지
- **Given** 구독 연결의 상대가 종료 신호 없이 사라졌다
- **Then** 약 1분 안에 연결 끊김을 감지하고 재연결 절차로 들어간다
