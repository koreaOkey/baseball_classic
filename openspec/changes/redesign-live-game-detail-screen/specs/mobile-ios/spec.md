## ADDED Requirements

### Requirement: 경기 상세 화면 야구장형 정보 구조
iOS 모바일 앱은 사용자가 진행 중인 경기 카드를 선택했을 때 Android와 동일한 정보 구조의 야구장형 상세 화면을 표시해야 한다(MUST).

#### Scenario: 진행 중 경기 상세 진입
- **GIVEN** 사용자가 진행 중인 경기 카드를 선택했을 때
- **WHEN** 경기 상세 화면이 표시되면
- **THEN** 화면은 점수판, 필드 프리뷰, 이닝 탭, 현재 승부, Apple Watch 동기화 상태, 실시간 이벤트 목록을 순서대로 표시한다

#### Scenario: 현재 경기 상태 표시
- **GIVEN** 경기 상태 데이터가 수신되었을 때
- **WHEN** 상세 화면이 렌더링되면
- **THEN** 홈/원정 점수, 현재 이닝, 공격 팀, B/S/O, 루상 점유, 투수, 타자, 투구수를 표시한다

#### Scenario: 필드 프리뷰 표시
- **GIVEN** 루상 점유 데이터와 투수/타자 정보가 수신되었을 때
- **WHEN** 필드 프리뷰가 표시되면
- **THEN** 베이스 점유 여부와 현재 투수/타자 이름을 야구장 형태의 시각 영역에 표시한다

#### Scenario: 이벤트 카드 표시
- **GIVEN** 실시간 이벤트 목록이 수신되었을 때
- **WHEN** 이벤트 목록이 표시되면
- **THEN** 각 이벤트는 이벤트 유형, 발생 시각, 설명, 가능한 경우 투수와 타자 이름을 표시한다

#### Scenario: 데이터 없음 상태
- **GIVEN** 선택된 경기 ID가 없거나 경기 상태를 아직 수신하지 못했을 때
- **WHEN** 상세 화면이 표시되면
- **THEN** 사용자가 이해할 수 있는 빈 상태 또는 로딩 상태를 표시한다
