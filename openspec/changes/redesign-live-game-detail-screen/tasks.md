## 6. Layout Centering & Diamond Tightening

- [x] 6.1 양 플랫폼에서 점수 텍스트를 팀 로고/팀명과 가로 중앙 정렬한다.
- [x] 6.2 양 플랫폼 점수판 중앙 진루 다이아몬드의 베이스 크기를 키우고 베이스 간 빈 공간을 줄여 4개가 한 다이아몬드로 보이게 한다.
- [x] 6.3 상세 상단바의 "경기 상세 / 경기 중 · 몇회" 텍스트를 좌측에서 화면 가로 중앙으로 이동한다(뒤로가기·LIVE 뱃지는 좌우에 유지).
- [x] 6.4 GameState 응답의 `batter`가 비어 있을 때 최신 이벤트의 `batter`(공백 트림 후)로 fallback해서 점수판/필드/현재 승부 카드 모두 타자 이름이 표시되게 한다. 투수도 동일하게 처리.
- [x] 6.5 상세 상단바의 서브타이틀("경기 중 · N회") 줄을 제거하고 "경기 상세" 타이틀만 노출한다(현황은 LIVE 뱃지·스코어보드 헤더로 충분).
- [x] 6.6 워치 동기화 카드를 상단바 LIVE 뱃지 옆 캡슐 뱃지(시계 아이콘 + 상태 컬러 점)로 합친다. 탭하면 iOS는 alert, Android는 Toast로 동기화 상세 메시지를 보여준다. 색 규칙은 기존과 동일(초록=현재 경기, 노랑=다른 경기, 회색=꺼짐).
