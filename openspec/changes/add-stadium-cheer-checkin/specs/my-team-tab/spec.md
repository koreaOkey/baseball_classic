## ADDED Requirements

### Requirement: 하단 탭 4번째 항목 추가
앱 하단 탭에 기존 `홈` / `상점` / `설정` 옆 4번째 항목으로 `내 팀` 탭이 등록되어야 한다(SHALL). 플랫폼별 활성화 플래그에 따라 노출 여부를 제어할 수 있어야 한다.

#### Scenario: 비활성 플랫폼 미노출
- **WHEN** 특정 플랫폼의 `내 팀` 탭 활성화 플래그가 꺼져 있다
- **THEN** 해당 플랫폼 사용자에게 `내 팀` 탭은 보이지 않는다
- **AND** 기존 3개 탭(`홈`, `상점`, `설정`) UI는 영향받지 않는다

#### Scenario: 활성 플랫폼 노출
- **WHEN** 특정 플랫폼의 `내 팀` 탭 활성화 플래그가 켜져 있다
- **THEN** 해당 플랫폼 하단 탭 4번째 항목으로 `내 팀`이 노출된다
- **AND** 탭 탭하면 응원 랭킹 콘텐츠가 표시된다

### Requirement: 응원 랭킹 콘텐츠 표시
`내 팀` 탭은 1차 콘텐츠로 팀별 응원 누적 체크인 랭킹을 표시해야 한다(SHALL). 주간·시즌 토글과 사용자 본인 응원팀 순위 강조를 포함한다. 팀 목록은 `DOOSAN`, `LG` 같은 팀 코드를 노출하지 않고 `베어스`, `트윈스` 같은 표시명을 사용해야 한다.

#### Scenario: 주간/시즌 토글
- **WHEN** 사용자가 주간·시즌 토글을 전환한다
- **THEN** 해당 단위의 팀별 순위가 표시된다

#### Scenario: 주간 탭 우선 표시
- **WHEN** 사용자가 `내 팀` 탭의 랭킹 화면을 처음 연다
- **THEN** 주간 랭킹 탭이 먼저 선택되어 표시된다
- **AND** 토글 순서는 `주간`, `시즌` 순서이다

#### Scenario: 마스코트명만 표시
- **WHEN** 사용자가 응원 랭킹의 팀 목록을 본다
- **THEN** 각 행의 팀명은 `베어스`, `트윈스`처럼 표시된다
- **AND** `DOOSAN`, `LG` 같은 팀 코드는 표시되지 않는다

#### Scenario: 내 팀 위치 강조
- **WHEN** 사용자가 응원팀을 설정한 상태에서 랭킹을 본다
- **THEN** 본인 응원팀 행이 시각적으로 강조된다

### Requirement: 경기장 체크인 허브
경기장 체크인, 워치 응원 안내, 팀별 체크인 랭킹은 `내 팀` 탭 안에서 하나의 허브 화면으로 제공되어야 한다(SHALL). 홈 화면은 경기장 체크인의 주 진입점이 아니며, 알림 탭 또는 앱 내 fallback 진입은 `내 팀` 탭으로 연결되어야 한다(SHALL).

#### Scenario: 내 팀 탭 메인 진입
- **WHEN** 사용자가 `내 팀` 탭을 연다
- **THEN** 선택 응원팀과 오늘 경기 상태를 요약하는 헤더가 표시된다
- **AND** 경기장 체크인 카드와 팀별 체크인 랭킹이 같은 화면 안에 표시된다
- **AND** 헤더의 `구장 체크인`, `워치 응원`, `랭킹` 버튼을 탭하면 각 기능 설명이 팝업으로 표시된다

#### Scenario: 체크인 가능 상태
- **WHEN** 사용자가 구장 반경 내에 있고 본인 응원팀이 해당 구장에서 오늘 경기 중이다
- **THEN** `내 팀` 탭의 경기장 체크인 카드에 구장 히어로 비주얼과 체크인 CTA가 표시된다
- **AND** 히어로 비주얼 오른쪽 상단에는 오늘 응원팀이 경기하는 구장명과 지역이 표시된다
- **AND** 해당 구장명과 지역은 선택 응원팀의 홈구장이 아니라 오늘 경기 데이터의 홈팀 구장을 기준으로 표시된다
- **AND** 체크인 완료 후 같은 카드가 완료 상태로 전환된다

#### Scenario: 체크인 카드 주요 컴포넌트 표시
- **WHEN** 사용자가 체크인 가능 상태의 경기장 체크인 카드를 본다
- **THEN** 카드 상단에는 경기장과 위치 핀을 표현한 히어로 비주얼이 표시된다
- **AND** 본문 아래에는 전체 폭의 `체크인하기` 버튼이 표시된다
- **AND** 버튼 아래에는 위치 확인이 끝났음을 알려주는 상태 컴포넌트가 표시된다

#### Scenario: 경기장 반경 밖 상태 표시
- **WHEN** 사용자가 오늘 응원팀 경기 구장 기준 500m 밖에 있다
- **THEN** 경기장 체크인 카드의 위치 상태 문구는 `위치 확인 완료`가 아니라 `현재 경기장 장소가 아닙니다`로 표시된다
- **AND** 체크인 CTA는 사용자가 시도할 수 있도록 표시된다

#### Scenario: 경기장 반경 밖 체크인 차단
- **WHEN** 사용자가 오늘 응원팀 경기 구장 기준 500m 밖에서 `체크인하기`를 탭한다
- **THEN** 체크인은 완료 처리되지 않는다
- **AND** 선택한 응원팀 표시명을 사용해 `<응원팀> 경기 구장이 아닙니다.`라는 팝업이 표시된다

#### Scenario: 체크인 버튼 완료 상태 전환
- **WHEN** 사용자가 체크인 가능 상태에서 `체크인하기` 버튼을 탭한다
- **THEN** 같은 카드가 체크인 완료 상태로 전환된다
- **AND** 사용자는 체크인이 완료되었다는 문구를 볼 수 있다

#### Scenario: 하루 1회 체크인 상태 유지
- **GIVEN** 사용자가 오늘 구장 체크인을 완료했다
- **WHEN** 사용자가 앱을 종료한 뒤 같은 날 다시 실행한다
- **THEN** 경기장 체크인 카드는 체크인 완료 상태로 유지된다
- **AND** 같은 사용자는 다음 날이 되기 전까지 같은 응원팀으로 다시 체크인할 수 없다

#### Scenario: 체크인 즉시 랭킹과 내 기록 반영
- **WHEN** 사용자가 `체크인하기` 버튼을 탭해 오늘 체크인을 완료한다
- **THEN** 내 응원팀 주간 랭킹 집계는 즉시 1회 증가한 상태로 표시된다
- **AND** `내 직관 기록`의 이번 주 및 시즌 체크인 횟수에도 같은 체크인이 즉시 반영된다

#### Scenario: 기능 설명 팝업 표시
- **WHEN** 사용자가 `구장 체크인`, `워치 응원`, `랭킹` 버튼 중 하나를 탭한다
- **THEN** 선택한 기능의 목적과 동작 방식이 팝업으로 표시된다
- **AND** 팝업을 닫으면 `내 팀` 탭 화면 상태는 유지된다

#### Scenario: 권한 또는 경기 없음 상태
- **WHEN** 위치·알림 권한이 없거나 오늘 본인 응원팀 경기가 없다
- **THEN** `내 팀` 탭은 체크인 CTA 대신 필요한 다음 행동 또는 경기 없음 상태를 안내한다
- **AND** 팀별 체크인 랭킹은 계속 표시된다

#### Scenario: 워치 응원 안내 표시
- **WHEN** 오늘 본인 응원팀의 응원 시각이 존재한다
- **AND** 사용자가 `워치 응원` 버튼을 탭한다
- **THEN** 워치 풀스크린 응원 예정 시각, 응원 문구, 팀 컬러 미리보기가 팝업으로 표시된다
- **AND** 폰 화면 변화 없이 워치에 발화된다는 설명이 함께 표시된다

### Requirement: 향후 콘텐츠 확장 자리 확보
`내 팀` 탭 컨테이너는 향후 팀별 뉴스 / 개인 체크인 달력 등 추가 콘텐츠를 임베드할 수 있는 구조여야 한다(SHALL). 현재 단계에서 뉴스·달력 화면을 구현하지는 않는다.

#### Scenario: 뉴스 자리 확장
- **WHEN** 후속 change에서 팀별 뉴스 화면이 추가된다
- **THEN** `내 팀` 탭 컨테이너 내부에 segmented control 또는 navigation으로 추가될 수 있다
- **AND** 기존 응원 랭킹 콘텐츠는 유지된다

#### Scenario: 개인 체크인 달력 자리 확장
- **WHEN** 후속 change에서 본인 체크인 이력을 달력 UI로 보여주는 화면이 추가된다
- **THEN** `내 팀` 탭 내부 segmented(랭킹 / 내 체크인 / 뉴스)로 진입점이 마련될 수 있다
- **AND** 백엔드 `GET /cheer-events/me` 엔드포인트와 `idx_cheer_events_user_clientts` 인덱스를 그대로 활용한다
