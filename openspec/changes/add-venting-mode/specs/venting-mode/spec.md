# venting-mode — 분풀이 모드 (Phase 1: iOS 목업)

## ADDED Requirements

### Requirement: 분풀이 모드 오픈 조건
시스템은 마이팀을 설정한 사용자의 팀이 패배한 경기에 한해, 경기 당일(KST 자정 전)에만 분풀이 모드를 오픈해야 한다(SHALL). 무승부·취소·연기 경기와 마이팀 미설정 사용자에게는 오픈하지 않아야 한다(SHALL NOT). Phase 1에서는 경기 결과·날짜를 목업 데이터로 주입하되 판정 로직은 실제 코드로 동작해야 한다(SHALL).

#### Scenario: 마이팀 패배 당일 오픈
- **WHEN** 목업 데이터의 경기가 마이팀 패배이고 경기 날짜가 오늘(KST)이면
- **THEN** 분풀이 모드 진입 카드가 노출된다

#### Scenario: 무승부 경기 미오픈
- **WHEN** 목업 데이터의 경기 결과가 무승부이면
- **THEN** 분풀이 모드 진입 카드가 노출되지 않는다

#### Scenario: 자정 경과 후 만료
- **WHEN** 경기 날짜가 어제(KST 기준 자정 경과)이면
- **THEN** 분풀이 모드 진입 카드가 노출되지 않는다

### Requirement: 아쉬운 순간 후보 선택
분풀이 모드는 "오늘의 아쉬운 순간" 후보 목록을 표시해야 한다(SHALL): 선수 후보 최대 5명(이름 + 사건 문구, 예: "8회 병살 1")과 항상 마지막에 고정되는 감독 항목. 후보가 5명 미만이어도 있는 후보만 부분 표시하고 진입을 차단하지 않아야 한다(SHALL). 화면에는 "기록 기반 자동 선정이며 공식 평가가 아닙니다" 면책 문구를 상시 표시해야 한다(SHALL). Phase 1의 후보 데이터는 클라이언트 목업 제공자가 반환한다.

#### Scenario: 후보 5명 + 감독 표시
- **WHEN** 목업 제공자가 선수 5명을 반환하면
- **THEN** 선수 5명(이름+사건 문구)과 6번째 감독 항목, 면책 문구가 함께 표시된다

#### Scenario: 후보 부족 시 부분 표시
- **WHEN** 목업 제공자가 선수 2명만 반환하면
- **THEN** 선수 2명과 감독 항목이 표시되고 선택·진입이 정상 동작한다

#### Scenario: 후보 선택 시 룸 진입
- **WHEN** 사용자가 후보 1명을 선택하면
- **THEN** 분풀이 룸으로 전환된다

### Requirement: 분풀이 룸 파괴 메커니즘
분풀이 룸은 익명 팀 유니폼 펭귄 인형과 데미지 게이지를 표시해야 한다(SHALL). 인형에는 선수 이름·등번호·실제 외형 요소를 표시하지 않아야 한다(SHALL NOT). 탭 연타로 게이지가 증가하며, 게이지 33%에서 균열, 66%에서 터짐, 100%에서 완파 연출로 전환되어야 한다(SHALL). 탭마다 경햅틱, 단계 전환 시 중햅틱, 완파 시 성공 햅틱을 재생해야 한다(SHALL).

#### Scenario: 탭 연타로 게이지 증가
- **WHEN** 사용자가 인형을 탭하면
- **THEN** 게이지가 증가하고 경햅틱이 재생된다

#### Scenario: 단계 전환 연출
- **WHEN** 게이지가 33% 또는 66% 임계값을 넘으면
- **THEN** 인형 이미지가 균열/터짐 단계로 교체되고 중햅틱이 재생된다

#### Scenario: 완파
- **WHEN** 게이지가 100%에 도달하면
- **THEN** 완파 연출과 성공 햅틱이 재생되고 완파 화면으로 전환된다

#### Scenario: 파괴 중 이탈 후 재진입
- **WHEN** 파괴 진행 중 룸을 이탈했다가 같은 경기에서 재진입하면
- **THEN** 게이지는 0부터 다시 시작한다

### Requirement: 완파 후 재도전
완파 화면은 "분풀이 완료" 상태와 재도전 버튼을 표시해야 한다(SHALL). 재도전 허용 여부는 게이트 제공자 프로토콜로 판정하며, Phase 1의 게이트 구현체는 광고 없이 항상 허용한다(SHALL). 경기당 첫 완파 여부는 로컬 저장소에 기록되어야 한다(SHALL) — Phase 2 광고 게이트 연결 시 그대로 사용한다.

#### Scenario: 재도전으로 재파괴 라운드 시작
- **WHEN** 완파 화면에서 재도전 버튼을 누르면
- **THEN** 게이지가 초기화된 분풀이 룸으로 재진입한다

#### Scenario: 첫 완파 기록
- **WHEN** 해당 경기에서 처음 완파에 도달하면
- **THEN** 경기 식별자 기준 첫 완파 완료가 로컬에 기록된다

### Requirement: Phase 1 피처 게이트
분풀이 모드 전체는 DEBUG 빌드 + 로컬 토글의 이중 게이트 뒤에 있어야 한다(SHALL). 릴리즈 빌드에서는 어떤 화면·카드도 노출되지 않아야 한다(SHALL NOT).

#### Scenario: 릴리즈 빌드 미노출
- **WHEN** 릴리즈 구성으로 빌드하면
- **THEN** 분풀이 모드 진입 카드와 화면이 포함되지 않는다
