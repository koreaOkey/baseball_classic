# mobile-ios — 분풀이 모드 홈카드 (Phase 1 델타)

## ADDED Requirements

### Requirement: 분풀이 모드 홈카드
iOS 홈 화면은 분풀이 모드 오픈 조건이 충족된 경우 "오늘의 아쉬운 순간" 카드를 표시해야 한다(SHALL). 카드에는 패배 스코어와 분풀이 진입 버튼이 포함되어야 하며, 오픈 조건 미충족 시 카드는 렌더링되지 않아야 한다(SHALL NOT). Phase 1에서 이 카드는 DEBUG 빌드 + 로컬 토글 게이트 뒤에서만 노출된다.

#### Scenario: 패배 당일 홈카드 노출
- **WHEN** DEBUG 빌드에서 분풀이 토글이 켜져 있고 목업 경기가 마이팀 패배 당일이면
- **THEN** 홈 화면에 패배 스코어와 진입 버튼이 있는 분풀이 카드가 표시된다

#### Scenario: 카드 탭으로 선택 화면 진입
- **WHEN** 사용자가 분풀이 카드의 진입 버튼을 탭하면
- **THEN** 아쉬운 순간 후보 선택 화면으로 전환된다

#### Scenario: 조건 미충족 시 기존 홈 유지
- **WHEN** 분풀이 오픈 조건이 충족되지 않으면
- **THEN** 홈 화면은 기존 카드 구성 그대로 표시된다
