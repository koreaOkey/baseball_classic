# whats-new-popup — 슬라이드형 업데이트 안내 델타

## MODIFIED Requirements

### Requirement: 대표 기능 슬라이드 안내
릴리즈 노트에 `featurePages`가 있으면 업데이트 안내는 **슬라이드형 카드**로 MUST
표시한다: 대표 기능 이미지 페이지들 → 마지막 텍스트 불릿 페이지. 카드 높이는 고정
(페이지 전환 시 크기 불변)이며, 스와이프·닷 탭·하단 버튼("다음", 마지막 페이지 "확인")
모두로 이동할 수 있다. `featurePages`가 비어 있으면 기존 단일 불릿 모달을 유지한다.

#### Scenario: 1.1.8 첫 실행 슬라이드 노출
- GIVEN 기존 유저가 1.1.8로 업데이트 후 처음 실행할 때
- WHEN 업데이트 안내가 뜨면
- THEN 분풀이(룸 스크린샷) → 잠금 화면(시계 프레임 + 노티 카드) → 그 외 개선 불릿
  3페이지 슬라이드가 표시되고, 마지막 페이지 "확인"으로 닫힌다

#### Scenario: 버튼만으로 완주 가능
- GIVEN 유저가 스와이프 제스처를 쓰지 않을 때
- WHEN 하단 버튼("다음")을 반복 탭하면
- THEN 마지막 페이지까지 이동 후 "확인"으로 닫을 수 있다

#### Scenario: 중간 닫기 후 재노출 없음
- GIVEN 유저가 1페이지에서 배경 탭으로 닫았을 때
- WHEN 앱을 다시 실행하면
- THEN 버전 게이트(last_seen_update_version)가 이미 기록되어 재노출되지 않고,
  설정 "업데이트 안내"에서 다시 볼 수 있다

#### Scenario: featurePages 없는 버전 호환
- GIVEN 이후 버전의 릴리즈 노트에 featurePages가 없을 때
- WHEN 업데이트 안내가 뜨면
- THEN 기존 단일 불릿 모달 레이아웃으로 표시된다
