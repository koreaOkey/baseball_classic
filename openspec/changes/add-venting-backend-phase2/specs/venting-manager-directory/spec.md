## ADDED Requirements

### Requirement: 팀별 감독 디렉터리

시스템은 팀별 감독명을 조회할 수 있는 디렉터리를 제공해야 한다(SHALL). 데이터는 시즌 단위로 수동 관리되며, 경질·교체 시 수동 갱신한다. 저장은 신규 테이블(`team_manager`)로 하며 기존 테이블을 변경하지 않는다.

#### Scenario: 팀 감독 조회
- **WHEN** regret-top5 산정 또는 응답 조립이 특정 팀의 현재 감독을 필요로 한다
- **THEN** 시스템은 `team_manager`에서 해당 팀 코드의 현재 시즌 감독명을 반환한다

#### Scenario: 감독 데이터 부재 시 안전 처리
- **WHEN** 특정 팀의 감독 레코드가 없다
- **THEN** 시스템은 오류 없이 감독 항목을 생략하거나 중립 레이블로 대체하고, 선수 후보 응답은 정상 반환한다

#### Scenario: 시즌 단위 관리
- **WHEN** 새 시즌 데이터 또는 감독 교체가 수동 입력된다
- **THEN** 조회는 현재 시즌 기준 감독명을 반영한다
