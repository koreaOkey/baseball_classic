## ADDED Requirements

### Requirement: 전체 팀 순위 목록 조회
사용자는 KBO 시즌의 전체 팀 순위와 주요 기록을 조회할 수 있어야 한다(MUST).

#### Scenario: 전체 팀 순위 목록 조회
- **GIVEN** KBO 시즌 팀 기록이 저장되어 있을 때
- **WHEN** 사용자가 전체 팀 순위를 조회하면
- **THEN** 시스템은 모든 팀의 순위, 팀명, 경기 수, 승/패/무, 승률, 게임차, 연속 결과를 순위순으로 반환한다

#### Scenario: 저장된 팀 순위가 없을 때
- **GIVEN** 요청한 시즌의 팀 기록이 저장되어 있지 않을 때
- **WHEN** 사용자가 전체 팀 순위를 조회하면
- **THEN** 시스템은 빈 목록을 반환하고 오류로 처리하지 않는다

### Requirement: 모바일 홈 팀 순위 팝업
모바일 사용자는 홈 화면에서 전체 KBO 팀 순위를 팝업으로 확인할 수 있어야 한다(MUST).

#### Scenario: 홈 화면 순위 아이콘 클릭
- **GIVEN** 사용자가 모바일 홈 화면을 보고 있을 때
- **WHEN** 사용자가 팀 순위 아이콘을 선택하면
- **THEN** 시스템은 전체 KBO 팀 순위를 팝업으로 표시한다

#### Scenario: 순위 데이터 로딩 실패
- **GIVEN** 전체 팀 순위 데이터를 불러올 수 없을 때
- **WHEN** 사용자가 팀 순위 팝업을 열면
- **THEN** 시스템은 실패 상태를 표시하고 기존 홈 화면 흐름은 유지한다
